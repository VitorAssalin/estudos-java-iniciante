## 📌 Conteúdos Praticados

- **Sintaxe Básica:** Declaração de variáveis, tipos primitivos e operadores.
- **Entrada e Saída de Dados:** Leitura de dados via consola (`Scanner`) e exibição de mensagens.
- **Estruturas de Controle:** Tomada de decisões (`if`, `else`, `switch`) e estruturas de repetição (`while`, `for`).
- **Funções e Métodos:** Organização e reutilização de blocos de código.
